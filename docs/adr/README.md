# 架构决策记录（ADR）

> 最后更新：2026-11-09
> 状态：生效

## 1. 规范

每个 ADR 记录一个不可逆或高成本决策，包含：

- 标题、状态、日期。
- 背景。
- 决策。
- 备选方案。
- 影响。
- 回滚/重新评估条件。

状态：`提议`、`已接受`、`已废弃`、`被取代`。
