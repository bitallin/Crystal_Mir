# 许可证与资源清单

> 最后更新：2026-11-10
> 状态：生效

## 1. 本仓库代码

| 路径 | 许可证 | 分发要求 |
| --- | --- | --- |
| `Client/` | MIT | 保留版权和许可声明 |
| `Shared/` | MIT | 保留版权和许可声明 |
| `Server/` | GPL-3.0-only | 分发二进制需提供完整对应源码 |
| `Server.MirForms/` | GPL-3.0-only | 同上 |
| `Tests/` | GPL-3.0-only | 同上 |
| 其他原始工具和文档 | 默认 MIT，除非另有说明 | 保留声明 |

控制面与 GPL 服务端代码隔离，详见 `docs/adr/0004-gpl-boundary.md`。

## 2. 外部资源

| 资源 | 许可证 | 分发结论 |
| --- | --- | --- |
| Crystal.Database | Unlicense | 可作为测试和开发资源；仍需确认其中素材的权利链 |
| Crystal.MapEditor | 未发现明确许可证 | 不进入发布包；先联系维护者或替换 |
| 传奇官方素材 | Wemade/Actoz 等权利方 | 不得默认视为可分发；需要授权或替换素材 |
| 第三方 NuGet 包 | 各自许可证 | 由 CI 的许可证扫描记录 |

控制面新增依赖：

| NuGet 包 | 许可证 | 用途 |
| --- | --- | --- |
| `Microsoft.AspNetCore.Authentication.JwtBearer` 8.0.6 | MIT | JWT 认证 |
| `Konscious.Security.Cryptography.Argon2` 1.3.1 | MIT | Argon2id 密码哈希 |

## 3. 素材分类

| 类型 | 示例 | 风险 |
| --- | --- | --- |
| 图库 | `Data/*.lib` | 高，通常来自官方客户端 |
| 地图 | `Maps/*.map` | 高，可能包含官方地图数据 |
| 音效 | `Sound/*` | 高，通常来自官方客户端 |
| 数据库内容 | 物品/怪物名称、数值 | 中，需确认数据权利 |
| 自制造素材 | 自制 UI、音效、地图 | 低，需保留来源和授权记录 |

## 4. 分发前检查

- [ ] 确认服务端二进制的 GPL 源码归档和获取方式。
- [ ] 保留 MIT/GPL/third-party notices。
- [ ] 确认 Crystal.MapEditor 许可证或移除依赖。
- [ ] 确认所有图库、地图、音效的授权。
- [ ] 运行依赖许可证扫描并保存报告。
- [ ] 记录发布包中每个素材的来源和许可证。
- [ ] 确认支付渠道和隐私合规要求。
