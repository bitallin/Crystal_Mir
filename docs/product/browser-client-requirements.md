# 浏览器客户端需求

> 最后更新：2026-11-19
> 状态：生效（实施中）

## 1. 目标

让玩家在电脑、手机和平板上打开浏览器直接进入 Crystal，无需安装桌面客户端；首版先覆盖现代主流浏览器和横屏移动设备，不追求旧设备和全功能对等。

成功标准是：同一测试区服可通过 Web 客户端完成登录、选角、进图、基础战斗、拾取、聊天、背包/装备、NPC 和断线重连，旧 Windows 客户端仍能正常使用。

本文描述首版目标和验收口径；当前实现进度与未验证项以 `docs/PROGRESS.md` 为准。已建立登录、选角、进图、移动、基础战斗、拾取、聊天、背包/装备、NPC/商店、角色创建/删除和重连链路，但不把未完成的真实素材动画、真机/Safari 验收写成已完成。

## 2. 目标用户与设备

| 用户 | 场景 | 关键要求 |
| --- | --- | --- |
| 桌面玩家 | 浏览器中长时间游玩 | 鼠标/键盘、流畅 60 FPS、完整 HUD |
| 手机玩家 | 碎片时间进入游戏 | 横屏、虚拟摇杆、触控按钮、低首屏 |
| 平板玩家 | 家庭/移动场景 | 横屏大画布、可缩放 HUD、触控与鼠标兼容 |
| 研究与演示人员 | 快速验证版本 | 无需安装、清晰的连接/版本/资源错误提示 |

浏览器基线：

- Chrome、Edge、Firefox、Safari 最新两个版本。
- iOS Safari 16.4+（服务端压缩包解码依赖 `DecompressionStream`）。
- Android Chrome 110+。
- WebGL2 必须可用；不支持时阻断并提示，不提供 Canvas2D 游戏降级。

## 3. 首版范围

### 3.1 必须支持

- 使用现有游戏账号登录。
- 查看角色列表；创建和删除角色（受服务端开关与校验约束）。
- 进入地图、切换地图、场景摄像机、基础移动。
- 普通攻击、受击、伤害数字、死亡与复活。
- 拾取地面物品。
- 当前聊天频道收发、系统消息展示。
- 背包、装备、消耗品使用、背包内物品移动/丢弃/装备。
- NPC 对话与基础商店买卖。
- 网络断开后的提示、退避重连和重新登录；不承诺无缝恢复战斗状态。
- 现代桌面和横屏手机/平板布局。

### 3.2 首版不包含

- 账号注册、改密、找回密码。
- 技能/魔法、高级战斗、宠物、英雄、内挂和复杂特效。
- 交易、邮件、拍卖、仓库、公会、任务、活动、商城。
- 桌面客户端全功能对等、竖屏 HUD、离线模式、云游戏串流、旧浏览器兼容。

## 4. 核心流程

```text
打开 /game/
  -> 加载应用壳和版本配置
  -> WSS 连接网关
  -> ClientVersion / Login
  -> 角色列表
  -> 创建或选择角色
  -> StartGame
  -> MapInformation
  -> 按需加载地图和图库
  -> 进入游戏循环
```

断线流程：

```text
连接丢失 -> 暂停输入 -> 断线遮罩
  -> 1/2/4/8/16 秒退避重连（最多 5 次）
  -> 重新 ClientVersion / Login
  -> 回到角色列表并继续
```

## 5. 交互原则

- 桌面：鼠标点击寻路、WASD/方向键移动、鼠标选目标、快捷键打开面板。
- 手机/平板：左侧虚拟摇杆、右侧攻击/拾取/背包按钮、点击目标；竖屏仅显示旋转提示。
- HUD 使用自适应 CSS 布局和原始素材纹理；不复制 WinForms 的固定坐标和控件树。
- 点击目标优先保持服务端权威：客户端只发送方向/动作请求，不直接修改生命、位置或物品状态。
- 所有阻断式错误必须有可读原因和重试入口：网关不可用、资源缺失、版本不匹配、WebGL2 不可用。

## 6. 非功能要求

| 维度 | 验收目标 |
| --- | --- |
| 首屏 | 应用壳约 2.5 MB gzip 以内；桌面宽带 3 秒内可交互，移动 4G 目标 6 秒内 |
| 地图 | 懒加载；再次进入优先命中缓存；缺资源时明确报错 |
| 帧率 | 桌面 1440×900 目标 60 FPS；受支持中端手机目标不低于 30 FPS |
| 内存 | 30 分钟会话无持续增长；地图切换释放旧纹理 |
| 安全 | 仅 WSS；Origin 白名单；不记录密码和包体；旧客户端仍可 TCP 登录 |
| 兼容 | 服务端游戏逻辑与协议语义不变 |

## 7. 验收场景

- 在桌面 Chrome 打开 `/game/`，使用已有账号登录、选角、进图、移动、攻击、拾取、聊天、打开背包并装备物品、与 NPC 对话。
- 在手机横屏视口完成同一核心闭环，摇杆和触控按钮可用；竖屏出现旋转提示。
- 拔网/重启网关后出现断线提示，重连成功回到角色列表。
- 资源版本不匹配、网关不可用、WebGL2 不可用时出现阻断提示。
- 旧 Windows 客户端连接同一区服仍能登录和进服。

## 8. 依赖与假设

- 首版使用已有游戏账号；测试角色由现有区服数据准备。
- 需要外部提供 `Client/Data`、`Client/Map`、`Client/Sound` 作为素材输入。
- 首版固定单区服；多区服路由、跨区会话和票据 SSO 后续设计。
- 资源素材按研究项目口径直接转码，不纳入本轮授权或商业化合规工作。
