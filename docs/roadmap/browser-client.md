# 浏览器客户端路线图

> 最后更新：2026-11-19
> 状态：生效（实施中）

估算假设为 3～4 人团队，包含前端、服务端、资源工具和测试能力；估算不是交付承诺。

当前实现进度以 `docs/PROGRESS.md` 为准。W0 已形成可运行的浏览器垂直闭环；W1/W2 已有代码和自动化冒烟，但真实素材动画、真机、Safari、音效与完整业务回归尚未闭环。

## W0 垂直切片（2～3 周）

- 建立 `Crystal.Web.Gateway`、`web-client/` 和协议样本生成器。
- 完成登录、选角、进图、单地图资源转换和基础移动。
- 通过网关在浏览器中进入同一测试区服。

验收：一个测试账号可在桌面 Chromium 完成登录、选角、进图和方向移动；旧 TCP 客户端不受影响。

状态：已闭环（真实区服版本门禁仍需联调）。

## W1 世界与资源底座（4～6 周）

- 完成 `.lib` 图集、`.map` 地图包、manifest 和确定性构建。
- 完成地图分层渲染、角色/怪物动画、摄像机、裁剪和基础 HUD。
- 完成桌面键鼠与移动横屏输入。

验收：进入测试地图可看到正确图层、门、角色和怪物动画；桌面与手机横屏均可操作。

状态：部分完成。地图图层、摄像机、输入、HUD 和资源管线已落地；Jev 1,698 张真实地图解析、479 张可覆盖地图和 45 个真实图库确定性编译通过，V1/V5/V100 地图严格资源加载冒烟通过；真实角色/怪物/NPC 动画、门/光照/音效仍待补。

## W2 可玩 MVP（5～7 周）

- 普通战斗、受击、死亡/复活、拾取、聊天。
- 背包、装备、消耗品、NPC 对话和基础商店。
- 角色创建/删除、断线重连、资源版本门禁。

验收：在桌面和移动横屏完成需求文档中的核心闭环；资源缺失和版本不匹配可阻断。

状态：部分完成。普通战斗、死亡/复活、拾取、聊天、背包/装备、NPC/商店、创建/删除和重连已有实现；真实 ZoneServer + Gateway 的 `ClientVersion` 构建哈希门禁已联调；临时真实账号已通过浏览器完成登录、创建角色和进入真实地图，但大图库加载期间的会话超时仍阻断移动验收，真机端到端和更多边界回归待补。

## W3 设备与稳定性（2～3 周）

- 真实 iPhone/Android 设备测试、视觉回归、性能预算和内存检查。
- 网关限流、背压、空闲关闭、指标和故障演练。
- 修复高优先级兼容问题，冻结首版验收矩阵。

验收：满足性能、兼容、安全与旧客户端并存要求；形成可复现的测试报告。

状态：未开始。网关限流、空闲关闭、帧上限和基础浏览器冒烟已具备，但完整设备矩阵、性能/内存、视觉回归和故障演练尚未执行。

## 依赖与风险

- 客户端 `Data/Map/Sound` 素材缺失会阻塞资源管线验证。
- `.lib`/`.map` 格式差异和移动端纹理内存是主要技术风险。
- 现有客户端协议包数量大，必须用 MVP allowlist 和逐字节样本测试控制回归。
- 首版不承诺战斗中断线无缝恢复，只保证重新登录和回到角色列表。
